Hi Temp Mail developer docs

Everything is free and keyless. The machine-readable contract is openapi.json (OpenAPI 3.1). AI agents can additionally call the MCP server at /.well-known/mcp or read llms.txt. Hi Temp Mail is receive-only: you can create mailboxes, read messages and download attachments, but sending email is not supported.

Base URL and the relay

Mail.tm's official API blocks cross-origin browser calls, so Hi Temp Mail exposes a same-origin relay that forwards requests verbatim and adds permissive CORS headers. Call the relay instead of api.mail.tm from browsers and serverless functions:

Base URL:  https://hitempmail.app/api/mailtm
Mirrors:   https://api.mail.tm  (primary)
           https://api.mail.gw  (automatic fallback)

Every path under the base URL maps 1:1 to the upstream API, including query strings. JSON bodies pass through untouched, attachment downloads stream through byte-identical, and only Content-Type and Authorization request headers are forwarded.

Note for self-hosters: Mail.tm IP-bans some shared serverless networks. The app therefore tries three bases in order — direct API, your own Cloudflare Worker relay, bundled relay — advancing automatically on failure. To run your own edge relay (free, ~10 minutes), see workers/README.md in the repository and set EDGE_RELAY in the app source.

Core endpoints

  • GET /domains — list active public domains to build addresses from.
  • POST /accounts {address, password} — register a mailbox. Address must use a listed domain.
  • POST /token {address, password} — exchange credentials for a Bearer JWT.
  • GET /messages?page=1 — list inbox messages (Bearer required).
  • GET /messages/{id} — fetch one message with body (Bearer required).
  • PATCH /messages/{id} {seen:true} — mark read (Bearer required).
  • DELETE /messages/{id} and DELETE /accounts/{id} — delete message / mailbox.

Minimal example (create + read)

BASE=https://hitempmail.app/api/mailtm

# 1. pick a domain
curl "$BASE/domains" | head -c 300

# 2. register a mailbox (address must use a listed domain)
curl -X POST "$BASE/accounts" -H 'Content-Type: application/json' \
  -d '{"address":"qa-run-4821@<domain>","password":"<random-16-chars>"}'

# 3. get a token
TOKEN=$(curl -s -X POST "$BASE/token" -H 'Content-Type: application/json' \
  -d '{"address":"qa-run-4821@<domain>","password":"<random-16-chars>"}' \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')

# 4. poll the inbox
curl -H "Authorization: Bearer $TOKEN" "$BASE/messages?page=1"

Limits, errors, fair use

Upstream rate limits apply (roughly 30 requests/minute per client); on HTTP 429 back off and retry with a short delay. The relay times out after 20 seconds and answers 502 with a JSON error body when every upstream fails. Mailboxes and messages live on Mail.tm infrastructure and may expire or be rate-limited without notice — never route anything important through disposable addresses, and never use them for banking, government, healthcare or work accounts. Abuse (spam, fraud, ban evasion) violates the acceptable-use terms.

MCP server for AI agents

Claude, ChatGPT and other agents can call Hi Temp Mail natively over Streamable HTTP at https://hitempmail.app/.well-known/mcp. Send JSON-RPC initialize, then tools/list to discover tools such as get_domains (list active mail domains) and server_health (relay status). No authentication, no session required — the endpoint is stateless.
